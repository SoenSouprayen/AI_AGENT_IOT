Comprendre cette démonstration et ses limites ＋

Python décide. Le LLM explique. Seul le PER prédit est optimisé, pas le débit ni l’énergie. Ces entrées viennent du CSV d’entraînement : ce n’est pas un test indépendant.

Les deux taux Doppler diffèrent entre modes dans le CSV. Comme dans l’application en ligne de commande, cette vue réutilise les features d’une ligne DR8 pour comparer les huit candidats. L’adaptation géométrique de la sélection n’est pas validée.
